# 공판장 가격수집

전국 공영도매시장(농협 공판장 포함)의 **정산 경락가격**을 매일 모아서
엑셀 파일과 웹 대시보드로 보여주는 프로그램입니다.

- 데이터 출처: 공공데이터포털 [한국농수산식품유통공사_전국 공영도매시장 정산정보](https://www.data.go.kr/data/15141809/openapi.do)
- 시장 목록 찾기: [전국 공영도매시장 실시간 경매정보](https://www.data.go.kr/data/15141808/openapi.do)

## 처음 한 번만

1. [공공데이터포털](https://www.data.go.kr) 로그인 → 위 두 API 페이지에서 각각 **활용신청** (자동 승인)
2. 마이페이지 → 개발계정 → **인증키** 복사
3. `.env` 파일을 메모장으로 열어 `API_KEY=` 뒤에 붙여넣고 저장
   (승인 직후에는 키가 동작하기까지 1시간 정도 걸릴 수 있습니다)

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 지금 수집하기 (최근 3일) | `가격수집 실행.bat` 더블클릭 |
| 대시보드 보기 | `대시보드 열기.bat` 더블클릭 → 브라우저가 열림 |
| 관심 품목 등록 | 목록이나 상세 화면에서 ☆ 누르기 → 맨 위에 큰 카드로 표시 (그때 고른 도매시장·법인 구분 기준으로 저장) |
| 관심 품목 해제 | 카드의 × 또는 ★ 다시 누르기 |
| 휴대폰으로 보기 | 아래 "부모님용 화면" 주소를 크롬으로 열기 (PC 대시보드는 이 PC에서만 열림) |
| 지난 기간 한꺼번에 받기 | `py collector.py --from 2026-09-01 --to 2026-09-29` |
| 도매시장 목록 새로 찾기 | `py collector.py --refresh-markets` |

## 결과물 위치

- `엑셀/경락가_YYYY-MM-DD.xlsx` — 날짜별 파일. **품목별 요약** 시트와 **전체 경락가** 시트
- `data/prices.db` — 모든 수집 데이터 (대시보드가 읽음)
- `data/markets.json` — 수집 대상 도매시장 코드 목록 (직접 고쳐도 됨)
- `data/watchlist.json` — PC 대시보드의 관심 품목 목록
- `logs/collect.log` — 수집 기록과 오류

## 가격 읽는 법

- **평균가 / 최저가 / 최고가**: 한 단위(예: 10kg 상자) 기준 경락가, 원
- **가중평균가**: 여러 시장·등급을 합칠 때 거래 건수 비중대로 낸 평균
- **전일비**: 바로 전 경매일 가중평균가 대비 변동률. 일요일·연휴처럼 하루 정산이 1,000건 미만인 날은 경매일로 치지 않습니다
- 금액이 0 이하인 정정·취소 행은 평균가·최저가 계산에서 뺍니다 (엑셀 "전체 경락가" 시트에는 원본 그대로 있음)
- **공판장**은 법인명 끝에 `(공)`이 붙은 곳입니다 (예: 농협가락(공), 광주원협(공)). 대시보드의 "법인 구분 → 공판장만"으로 골라 볼 수 있습니다
- 같은 품목도 **단위가 다르면 따로** 집계됩니다 (예: 사과 10kg / 사과 5kg)

## 부모님용 화면 (인터넷)

주소: **https://thehada0011-hub.github.io/sise/**

- 70~80대가 쓰기 쉽게 만든 화면 (`web/simple.html`): 큰 "말로 물어보기" 버튼, 품목 화면(큰 가격·두 달 그래프·전국 시장별 시세), 글자로 찾기, 즐겨찾기, 소리로 읽어주기, 글씨 크게
- 가격은 모두 전국 평균입니다. 즐겨찾기는 각 휴대폰 안에 저장되고, 처음 열면 `favorites.json`의 품목이 들어갑니다
- 갤럭시: **크롬**으로 열고 메뉴 → "앱 설치"(또는 "홈 화면에 추가")를 누르면 앱처럼 쓸 수 있습니다. 말로 묻기는 크롬에서 동작합니다
- PC에서 미리 보기: 대시보드를 켠 뒤 http://127.0.0.1:8517/simple.html

GitHub Actions(`.github/workflows/daily.yml`)가 매일 07:00·18:00(한국 시간)에 시세를 수집하고
`export_static.py`로 화면 파일을 만들어 GitHub Pages에 올립니다. PC가 꺼져 있어도 됩니다.
인증키는 저장소 Settings → Secrets의 `API_KEY`에만 들어 있습니다.

## 매일 자동 수집 (PC)

Windows 작업 스케줄러에 `공판장 가격수집` 작업으로 등록되어 **매일 오전 7시와 오후 6시**에 최근 3일치를 받습니다.
그 시간에 PC가 꺼져 있었으면 켜진 뒤 바로 실행됩니다.
최근 3일을 매번 다시 받는 이유는 정산이 늦게 올라오는 시장이 있어서이고, 다시 받아도 중복 저장되지 않습니다.

해제하려면 PowerShell에서:

```
Unregister-ScheduledTask -TaskName "공판장 가격수집" -Confirm:$false
```
